House Price Prediction System:

Project Name:House Price Prediction

Description: 
            This is a machine learning project Aim to build 
            a predictive model which will predicts the house
            prices based on features such as no.of room,area,
            no.of living rooms

Technology Used:
  • Numpy:Used for data retrieval and heavy mathematical computation
  • Pandas:Used for data processing and scaling the data
  • Scikit Learn:Used to train machine learning models like:
    • Linear Regression
    • Decision Tree Regressor
    • Random Forest
